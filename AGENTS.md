# AGENTS.md

Инструкции для AI-агента при работе над проектом «Киноманьяк».

## Общие правила

1. **Сначала читай SPEC.md и PLAN.md.** Они являются источником истины.
2. Соблюдай контракт из раздела 4 SPEC.md строго. Автопроверка (`kino_check.py`) проверяет именно его.
3. Не выдумывай год, длительность, страны и языки фильмов. Бери только из источника. Описание можно генерировать.
4. Ключи API никогда не коммить. Используй `.env` и `.env.example`.
   Обязательные переменные:
   - `OPENAI_API_KEY` + `OPENAI_BASE_URL` + `MODEL` (для работы модели)
   - `TELEGRAM_BOT_TOKEN` (только если делаешь Legendary / Telegram-бот)
5. Делай частые осмысленные коммиты. Для уровня Legendary: SPEC и тесты появляются **до** кода, который они описывают.
6. Все числа в README (токены, цена, доля пройденных запросов) должны быть получены реальными запусками `check.py` / `show.py`.

## Ключевые требования к коду

- `pick(client, model, query, films)` возвращает `(outcome, ids)`.
- При импорте `kino.py` ничего не запускается.
- Печать фильмов — из каталога, `why` — от модели.
- Все ошибки (сеть, API, ValidationError, refusal, length) обрабатываются, программа не падает.
- Журнал `calls.jsonl`: одна строка на вызов, поля `model`, `request`, `outcome`, при `invalid` — `rejected`.
- Для локальной модели `qwen3.5:4b` всегда передавай `reasoning_effort="none"`.

## Порядок работы (рекомендуемый)

1. Подготовь окружение (`uv init`, зависимости).
2. Создай/проверь `films.json` (минимум 40 фильмов, ≥5 казахстанских).
3. Реализуй схемы Pydantic и функцию `pick`.
4. Напиши тесты с заглушкой.
5. Реализуй `check.py` и `show.py`.
6. Заполни `queries.json` (15 для Common).
7. Прогони реальные запросы, обнови README.
8. При желании — Rare / Epic / Legendary.

## Уровни

- **Common** — обязательный (100%).
- **Rare**, **Epic**, **Legendary** — бонус. Можно делать независимо.

## Полезные команды

```bash
uv run kino.py "фильм как Интерстеллар, но не про космос"
uv run check.py
uv run show.py
uv run pytest
```

Если сомневаешься — смотри SPEC.md. Контракт важнее красоты кода.
